# Efficiency Pilot

A full-screen live HUD for an electric car (built for the BYD Sealion 7 / DiLink 5 head unit):
power/regeneration gauge, trip efficiency, range recovered, a recent-efficiency chart, motor RPM,
and a persistent efficiency rank with XP.

Built from scratch by parmahamsolo@gmail.com. Source is not published — this repo hosts release
downloads and update notes only.

## Download

See the [Releases](../../releases) page for the latest `.apk`. Install by sideloading (the app is
not on the Play Store).

## Install

1. Copy the `.apk` onto the car's tablet (USB, file share, whatever's easiest for you).
2. Open it with a file manager to install (you may need to allow "install from unknown sources"
   once).
3. Open the app, tap `...` (bottom right) for Setup, and follow the on-screen steps to allow the
   app to read the car's data.

## Updates

The app checks in periodically to confirm it's still a supported version. Watch this repo's
Releases page for new versions.
